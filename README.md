# CCCS–Cost（HONAM-M3冻结模型接入版）

该版本已替换原型演示公式，接入论文正式时间验证模型：

- 30个冻结共病节点、33条稳定正向边；
- 最大边权缩放、Leiden模块、6项拓扑特征、开发集标准化参数和普通PCA第一成分；
- HONAM-M3五种子集成模型及各自冻结预处理器；
- 开发集费用P80高费用界值：33,710.329815元；
- 预先固定的模型分类评价阈值：0.50；
- 单次COPD住院费用评估及CSV/XLSX批量预测；
- 中文主页和English version英文入口。

## 本地运行

```powershell
pip install -r requirements.txt
streamlit run app.py
```

批量入口可读取现有 `建模特征矩阵.xlsx` 的 `特征_标签` 工作表，并自动映射5个带前缀的二值字段。正式模型需要21个M3字段，输出集成概率、0.50分类及五个种子概率。

复现说明：若直接上传未完成相同预处理的旧版特征矩阵，缺失值将由冻结预处理器处理，因此对应概率可能与论文归档预测略有差异。需要逐行严格复现时，应上传与正式分析一致的21字段数据。

模型采用2011—2017年资料开发，并在2018—2020年新患者队列中进行单中心时间验证。超出研究中心或资料时段属于外推。该工具仅供研究复核，不用于临床诊疗、医保支付或资源配置决策。
